# Dependency manifest for the Linux-Native Virtualized Compute Cluster
# prototype (Deliverable A: bootstrap/, Deliverable B: management/).
#
# IMPORTANT: on RHEL, the libvirt/Ceph Python bindings are NOT pip packages.
# They are compiled against system libraries and must come from dnf. Mixing
# a pip-installed libvirt-python with the system libvirtd is a common source
# of "undefined symbol" errors, so this project deliberately keeps them out
# of `pip install -r requirements.txt` and installs them via dnf instead
# (see bootstrap/modules/packages.py and this repo's top-level README.md's
# "Quickstart" / "Deployment model" sections).
# ---------------------------------------------------------------------------
